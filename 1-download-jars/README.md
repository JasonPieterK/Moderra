# 1-download-jars - the finished files

Pick **one** jar: your server type + your Minecraft version.

`Antibadwords-RELEASE[SERVER TYPE] - 1-MINECRAFT VERSION.jar`

* `[Bukkit]` - Bukkit, Spigot, Paper &nbsp;|&nbsp; `[Purpur]` - Purpur &nbsp;|&nbsp; `[Fabric]` &nbsp;|&nbsp; `[Forge]`
* `1` is the release number of AntiBadWords (the numbering started over at 1).
* Versions: 26.3, 26.2, 26.1.2, 26.1.1, 26.1, 1.21.11.

Put the jar into `plugins/` (Bukkit, Spigot, Paper, Purpur) or `mods/` (Fabric, Forge). Do not put two AntiBadWords jars in.
Which jars exist right now is listed in the main [README](../README.md).
