# 2-plugin-bukkit-purpur - the plugin's source code

For Bukkit, Spigot, Paper and Purpur servers (one code base; Purpur runs Paper plugins).

The plugin itself is small: all rules live in the shared engine ([`../5-shared-engine`](../5-shared-engine/)), which the
build compiles into the jar together with the word lists from [`../7-wordlists`](../7-wordlists/).

| Where | What |
|-------|------|
| `src/main/java/.../ModerraPlugin.java` | the main class: starts the engine, registers listener and command |
| `.../BukkitPlatform.java` | what the engine needs from the server (players, messages, permissions, scheduler) |
| `.../ModerraListener.java` | hands chat, commands, signs, books and anvil renames to the engine |
| `.../PunishmentExecutor.java` | applies effects, attribute changes and sounds |
| `.../ModerraCommand.java` | forwards `/moderra` to the engine |
| `src/main/resources/plugin.yml` | plugin description, command and permissions |
| `build-all-versions.sh` | builds the Bukkit + Purpur jars for every Minecraft version |
| `test-on-real-server.sh` | starts a real server (you bring the server jar) and checks `/moderra` - **never run yet** |

There is no `config.yml` in this folder any more: the default config files are generated by the engine on the first
start. The unit tests moved to the engine too (`cd ../5-shared-engine && mvn test`).

`mvn clean package` builds one jar for 1.21.11. `./build-all-versions.sh` builds all of them into `../1-download-jars/`.

**Honest status:** GitHub Actions compiles this code against the real Spigot API. It has never run on a real server.
The finished jars are on GitHub Releases (see [`../1-download-jars/README.md`](../1-download-jars/README.md)). What still needs a real-server
test: [`../handoffs/BUILD-VERIFICATION-TODO.md`](../handoffs/BUILD-VERIFICATION-TODO.md).

## Console banner (`banner` package)

`ModerraPlugin` creates a `BannerService` at the end of `onEnable` and calls `cancel()` / `showShutdown()` in `onDisable`.
The service gathers its data on the main thread (on the first server tick for the animated variant) and animates on the
daemon thread `Moderra-Banner`, writing to the raw stdout (`FileDescriptor.out`) because the server logger prefixes every
line of `System.out`. Everything that decides or draws is pure and unit tested: `BannerTerminal` (TTY, `TERM`, `NO_COLOR`,
hosting-panel variables, size, config value), `BannerRenderer` (frames, compact, shutdown, plain summary), `Canvas`, `Tone`,
`ColorMode`, `BannerData`. Setting: `general.startup-banner` (`CoreSettings.STARTUP_BANNER`). Preview of the last frame:
`java -cp target/classes:target/test-classes com.jason.plugins.moderra.banner.BannerPreview <folder>`.

## What is new in this round

The listener now also hands the engine: the player name when somebody joins (`filters.scan.join-names`), the side of a
sign that was edited (`SignChangeEvent#getSide`, so `filters.scan.sign-back` works), and the command a command block or
command-block minecart is about to run (`ServerCommandEvent`, `filters.scan.command-blocks`). Chat is the one place
where a "censor" action really rewrites the text; everywhere else such a message is blocked.
New permission nodes in `plugin.yml`: `moderra.bypass.spam`, `.bypass.links`, `.bypass.evasion` (default: nobody).
None of this has been compiled against the real Spigot API or run on a server, see
[`../handoffs/BUILD-VERIFICATION-TODO.md`](../handoffs/BUILD-VERIFICATION-TODO.md).
